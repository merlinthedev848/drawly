How to Host on Enhance Host (Enhance Control Panel)

Enhance Host supports direct static HTML5 hosting (`public_html`) and Python WSGI apps.

Option A: Direct Static Host (Easiest)

  1. Open Enhance File Manager → public_html.
  2. Upload index.html and lotto_data.json.
  3. Your app runs immediately in any browser!

Option B: Python WSGI App

  1. In Enhance Panel, select Python Applications.
  2. Upload the project files and set entry point to app:app.
